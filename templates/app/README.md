# {{PKG_NAME}}

> A DeepSeek Harness **app plugin** that owns its own command line, generated by [`create-deepseek-harness-plugin`](https://www.npmjs.com/package/create-deepseek-harness-plugin).

## Why two files

The launcher parses only its own flags (`--profile`, `--patch`, the config dumps) and hands
everything after them to the tree verbatim. So an app owns its flag family, its `--help`, and
its parse errors — adding a flag never means touching the launcher.

| File | Role |
|---|---|
| `src/startup.ts` | injects `cmdlineArgs`, parses this app's flags, publishes what it resolved as a service |
| `src/index.ts` | the app; the patch row feeds it that service's value through `!!js` |

```yaml
- id: {{PLUGIN_ID}}
  inject: [{{PLUGIN_ID_CAMEL}}Startup]
  config:
    greeting: !!js ctx.{{PLUGIN_ID_CAMEL}}Startup.greeting ?? 'Hello, World!'
```

A flag therefore beats the configured value, with the deployment value written beside it as the
fallback. This precedence needs the expression to survive: a user patch that replaces the whole
`config` with literals removes the runtime read.

On `--help` the startup plugin never publishes its service, so the app row stays inactive.

## Quick start

```sh
pnpm install
pnpm run build

# From the PARENT directory:
dsh plugin --profile my-profile add ./{{PKG_NAME}}

dsh --profile my-profile                       # [{{PLUGIN_ID}}] Hello, World!
dsh --profile my-profile --greeting 'Good morning'   # [{{PLUGIN_ID}}] Good morning
dsh --profile my-profile --help                # this app's help, and nothing boots
```

Launcher flags must come before app arguments; the launcher's own parser stops at the first
token it does not recognize and everything from there belongs to the app.

## Dependencies pinned

Every `@deepseek-ai/*` package sits in `devDependencies` — build-time types only. At runtime the
plugin binds to the copies inside the running harness via `$DSH_HOME/profiles/node_modules`.

- `@deepseek-ai/dsh-cmdline`: `{{DSH_TOOLS_VERSION}}` (`parseCmdline`, pinned to your installed dsh)
- `@deepseek-ai/cordis`: `^{{CORDIS_VERSION}}`
- `commander`: the parser `parseCmdline` adapts
